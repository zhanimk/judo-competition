# API подготовки турниров

NestJS + Prisma + PostgreSQL. Доступ только на 127.0.0.1:4319. Текущая версия для локальной разработки, без авторизации; не публиковать наружу.

Ресурсы /api/v1/tournaments: список, создание, получение турнира; вложенное создание категорий и заявок. DTO проверяются сервером; даты, возраст и лимит 128 заявок проверяются сервисом. Сущности сохраняются в PostgreSQL.

В dev используется отдельная база judo_competition_dev. `.env` не коммитится, пример — `.env.example`. Prisma-схема и миграции находятся в prisma/. Команды из корня: npm run db:generate, npm run db:migrate, npm run dev:api.

Entry пока является заявкой, а не общим справочником спортсменов. Club — строка заявки; нормализованный справочник клубов ещё не реализован. Нет подтверждения допуска, снимков правил, жеребьёвки, редактирования, удаления, ролей, аудита, WebSocket и автономности. Максимальный вес — только верхняя граница; открытые и интервальные категории будут добавлены отдельно.
