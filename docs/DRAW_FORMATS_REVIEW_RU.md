# Виды сеток и призовые места — 16 октября 2026

Источник: [IJF Sport and Organisation Rules, 14.08.2026](https://78884ca60822a34fb0e6-082b8fd5551e97bc65e327988b444396.ssl.cf3.rackcdn.com/up/2026/08/IJF_Sport_and_Organisation_Rul-1787430903.pdf), разделы 2.5–2.6, страницы 37–42; схемы F1.3.7–F1.3.17, страницы 214–224. PDF получен с [официальной страницы IJF](https://www.ijf.org/ijf/documents/26). Просмотрена схема F1.3.7; пояснения ниже — пересказ и сопоставление с кодом проекта, не сертификация приложения.

## Что означает группа

Pool A/B/C/D на олимпийской схеме — части дерева выбывания. Это не означает, что каждый в A встречается с каждым. Большая сетка разбивается на части для чтения; результаты этих частей сходятся к полуфиналам и финалу. В приложении такое деление уже есть при размере дерева от 16 позиций (например, 9–16 реальных участников, остальные позиции BYE). Порог «больше 10» не является универсальным требованием IJF.

MIXED в приложении — другой формат: настоящие круговые группы, затем выход в плей-офф. Его нельзя автоматически включать из-за числа участников или называть олимпийским форматом.

## Подвиды

| Система                    | Кто попадает в утешение / бронзу                                                                                                                  | Состояние приложения                                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Quarter-final repechage    | Проигравшие четвертьфиналов борются в двух утешительных встречах; победители встречаются с проигравшими противоположных полуфиналов за две бронзы | Основные маршруты реализованы в REPECHAGE; собственный профиль, соответствие всему SOR не подтверждено                    |
| Double repechage           | Проигравшие четырём полуфиналистам получают путь через утешение                                                                                   | Не реализован как самостоятельный формат                                                                                  |
| Full repechage             | Проигравшие после каждого круга получают путь в утешение                                                                                          | Не реализован как самостоятельный формат                                                                                  |
| Direct knockout            | Без утешения; по SOR проигравшие полуфиналов получают по бронзе                                                                                   | Исторический SINGLE_ELIMINATION приложения имеет только 1/2; его нельзя выдавать за точную реализацию IJF Direct Knockout |
| Round robin                | Каждый с каждым; порядок определяется правилами ранжирования                                                                                      | Реализован, пользовательская политика побед и дополнительных процедур                                                     |
| Круговые группы → плей-офф | Сначала каждый с каждым внутри группы, затем квалификация                                                                                         | Реализован MIXED; это не деление олимпийской сетки на A/B/C/D                                                             |

В SOR олимпийские соревнования используют quarter-final repechage. Малые составы рассматриваются отдельно: таблица SOR различает 6+ и до 5 участников, с исключениями по типу события. Для 2 — золото и серебро, для 3–5 в малых составах предусмотрена одна бронза. Самостоятельно переносить это на пользовательский детский турнир нельзя: требуется его положение.

## Согласованное правило проекта

Пользователь 16 октября отдельно утвердил для круговой из 4–5 участников две бронзы: итоговые первые четыре получают 1, 2, 3, 3; пятый остаётся без медали, даже если у него есть победы. Порядок сначала устанавливается по действующей процедуре равенства: две равные записи — дополнительная встреча, три и более — дополнительный круг либо ручной порядок с причиной. Автоматического приоритета оценок нет.

Новое правило сохранено в custom-2026-v5 через roundRobinMedals=TWO_BRONZE_FOR_FOUR_FIVE. Старые snapshots без этого поля сохраняют прежние места. Спортивные параметры табло, основное время, удержание, Golden Score и правило трёх шидо не изменены. Расчёт ядра используется в публичных результатах, PDF и командном зачёте. При незавершённых встречах/неразрешённом равенстве имена призёров не появляются.

Последующее уточнение пользователя внедрено в custom-2026-v6: 2–5 участников — круговая, 6–7 — сетка с двумя бронзовыми встречами. При 6 участниках нет отдельных утешительных встреч: проигравшие реальных четвертьфиналов сразу выходят на противоположных проигравших полуфиналов. При 7 есть одна утешительная встреча. Пустые позиции BYE не создают фиктивных схваток, оценок или отдыха. С 8 участников сохраняется выбранный формат; явно выбранная большая круговая остаётся доступной. REPECHAGE показывает части дерева A/B/C/D, MIXED сохраняет настоящие круговые группы. Старые snapshots и их политика не меняются.
