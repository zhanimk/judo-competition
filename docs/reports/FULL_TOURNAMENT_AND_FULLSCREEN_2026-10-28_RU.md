# Полный прогон турнира и полноэкранное табло — 28 октября 2026

## Серверная репетиция

Повторная изолированная PostgreSQL-репетиция прошла 28 интеграционных наборов, проверки аварийного/штатного перезапуска, автономного журнала, резервной копии и неизменности опубликованных PDF. Временная схема удалена; машинный итог находится в `latest-rehearsal.json`.

Новый `scripts/tournament-matrix-integration.mjs` включён в обычную репетицию. Ядро завершает по одному детерминированному пути для каждого размера 2–128 при каждом из трёх входных значений формата: 381 путь. Политика TWO_FORMATS приводит их к круговой для 2–5 и сетке с утешением для 6–128. Это не перебор всех возможных исходов.

Через настоящий API полностью проведены 19 категорий: 2, 3, 4, 5, 6, 7, 8, 9, 15, 16, 17, 31, 32, 33, 63, 64, 65, 127, 128 участников. Всего 635 заявок, три татами, 683 подтверждённые схватки, 73 медали. Проверены круговой порядок очереди, зависимости, повтор подтверждения, конечный FINISHED, совпадение результатов публичного снимка с БД, командные медали и отсутствие оставшихся встреч. Остаток на табло проверяется до начала, после каждых ста подтверждений и в конце; учитываются ещё не заполненные участниками ветви.

Отдых ускорен только изменением времён окончания в одноразовой тестовой схеме. Облачные ограничения отдыха этим прогоном не отключаются. Равенства, дополнительные встречи и ручное разрешение проверяются отдельными наборами репетиции.

## PDF

Проверены три вида документов на русском и казахском: сетки/результаты, участники, командный зачёт. Для каждого проверены сохранённые байты и SHA-256, запрет анонимной загрузки до публикации и совпадение публичного файла после публикации. Проверены ФИО всех участников и медалистов в соответствующих документах.

Предыдущий полный комплект из этого же сценария отрисован в 456 страниц PNG: 130+130 страниц сеток, 56+52 участников, 44+44 командного зачёта с приложением состава. Автоматически проверены границы всех текстовых фрагментов: выходов за страницу нет. Просмотрены обзоры всех страниц и увеличенные образцы. Печатный принтер отдельно не проверялся. Файлы QA находятся в `output/pdf/full-tournament-qa/`, визуальные артефакты — в `tmp/pdfs/full-tournament-matrix/`.

## Полноэкранный пульт

Добавлены вход/выход из полного экрана, резервный режим заполнения окна для браузеров без доступного Fullscreen API, серверный остаток схваток и маркировка старого снимка при автономной работе. Победитель подтверждается явно внутри табло; затем доступен отдельный запуск следующей встречи с прежними серверными проверками. История и подготовка автономного режима скрыты в полном экране; ошибки связи, незавершённые команды и конфликты сохраняются.

В Chrome на отдельном локальном API проверены начисление, подтверждение, уменьшение остатка 18 → 17 → 16, запуск следующей встречи, сохранение полного экрана между встречами, выход и адаптация 1280×659, 1920×1080 и 390×844. Все четыре оценки имеют постоянные подписи, включая нули; белый спортсмен сверху, синий ниже, таймер снизу. На очень маленькой высоте доступна вертикальная прокрутка, горизонтального выхода на ширине 390 px нет.

## Границы приёмки

Локальная репетиция и браузерная проверка не заменяют завершение облачного турнира, проверку опубликованной версии, реальные телевизоры, Wi-Fi зала и отключение питания главного ноутбука. Статус облачного прогона фиксируется отдельно после фактического завершения.
